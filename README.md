# shut-the-box

A minimal Node + React + TypeScript project that displays "Hello World". Built with [Vite](https://vite.dev/).

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (comes bundled with Node.js)

## Running locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the URL printed in the terminal (typically [http://localhost:5173](http://localhost:5173)) in your browser.

## Other commands

- `npm run build` — type-checks and builds a production bundle into `dist/`
- `npm run preview` — serves the production build locally
- `npm run lint` — runs ESLint over the project
